# planck-layout

My first ever custom keyboard layout for [planck](https://olkb.com/collections/planck) keyboard.

Layout is based on default planck layout by Jack Humbert, repeating layer logic from my other custom [layout for Corne](https://github.com/alex-1121/corne-layout/) keyboard.

[layout.c](https://github.com/alex-1121/planck-layout/blob/main/layout.c) has a visual representation of layers in comments.
